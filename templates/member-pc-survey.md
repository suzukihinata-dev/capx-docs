# メンバー PC の調査票（テンプレート）

- 目的: ローカルで開発モード（基盤イメージ＋コードの差し込み）を使えるメンバーを把握する。使えないメンバーは計算環境の計算ノードで開発する。
- 状態: 2026-11-10 の班長方針で実施は見送り（動作確認・テストは計算環境で行う）。必要になったときのために残す。
- 取扱い: 回答（個人の端末情報）はリポジトリにも文書にも書かない。回答の CSV は共有しない場所に置き、記録するのは集計結果だけにする。

## 質問（Slack で送る文面）

```
【PC 環境の調査（任意・5分）】ローカルでコンテナを動かせるかを見積もるためです。
個人の端末情報は集計にだけ使い、リポジトリ等には載せません。
1. OS: Linux / Windows / macOS（Windows の場合 WSL2 を使えるか）
2. NVIDIA GPU の有無と型番（例: RTX 4090）
3. GPU のメモリ（VRAM, GB）
4. 空きディスク容量（GB）
5. 自分の PC で sudo（管理者権限）を使えるか: はい / いいえ
```

## 回答の記録形式（CSV）

```
id,os,wsl2,gpu,vram_gb,free_disk_gb,sudo
A,linux,,RTX 4090,24,500,yes
B,windows,yes,RTX 3060,12,200,yes
C,macos,,,,300,yes
```

`id` は担当記号（氏名やアカウント名は書かない）。

## 集計

```
python3 tools/pc_survey_summarize.py <回答の CSV>
```

区分:
- 区分 A: Linux＋NVIDIA GPU（VRAM 16GB 以上、空き 100GB 以上、sudo あり）→ ローカルで開発モード可
- 区分 B: Windows（WSL2）＋NVIDIA GPU → WSL2 で可能性あり（未検証）。当面は計算環境で開発
- 区分 C: それ以外 → 計算環境の計算ノードで開発
